# Data note (one page)

**What it is.** The supplied Ujjwal Rail kit (`data_kit/`): a fictional operator. All names, trains, fares, rules and passengers are invented. Phone numbers are only the last 4 digits.
Nothing is generated by us; `core/official.py` reads the kit as given. Point `DATA_KIT_DIR` at another folder (JSON or CSV files, extra columns allowed) to load judge-supplied data with no code change.

**How to check it.** `python scripts/validate_data.py` runs 42 checks (brief minimums, links between tables, amounts add up, seats within capacity, an after-midnight train, a shared station name).
`cd data_kit && python -m unittest discover -s tests` runs the kit's own 21 self-tests.

| Item | Where | Notes |
|---|---|---|
| Stations, trains, stops, fares, seats, passengers, bookings, travellers | `data_kit/data/synthetic/*.json` | money in paise; two stations share the city name Anandpur (ANPR, ANPN) |
| Dated settings | `data_kit/data/ujjwal_rail.db` table `setting_versions` | 93 rows with effective dates, so any date can be answered |
| Documents | `data_kit/data/policies` | 12 rules (RUL-001..012), 6 circulars (CIR-001..006), 20 FAQs (FAQ-001..020); see `documents_list.md` |
| Cases | `edge_cases.json`, `service_cancellations.json` | operator-cancelled service on 26 Nov (UJ1005), used by the refund tests |

**Pinned values used in tests.** BKG0001: P001, UJ1006 AC2 Arunoday to Chetakgarh, Rs 3,062.50, boards 25 Nov 09:15. BKG0002: P002, AC3, Rs 1,395. BKG0003: P003, FP, one confirmed and one waiting traveller. BKG0005 RAC. BKG0008/9/16 operator cancelled.

**Built-in conflicts (kept as supplied).** Circulars change the AC2 and AC3 cancellation charges (CIR-001 from 15 Nov) and the Tatkal supplements (CIR-002 from 20 Nov); some FAQs are older than the rules. The assistant shows the newest, highest-authority source and says when others disagree.

**Known limits.** No Tatkal booking in the kit. Distances and fares are the kit's own.
