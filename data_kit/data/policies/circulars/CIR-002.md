# Revised AC2 and AC3 Tatkal Supplements

## 1. Purpose

This circular revises two class-specific Tatkal supplements without changing the Tatkal booking window or refund restrictions.

## 2. Reference to Existing Rule

RUL-005 Section 3.3 sets the original AC2 supplement at INR 400 and the original AC3 supplement at INR 300 per traveller.

## 3. Amendment Details

| Field | Value |
|---|---|
| Original rule | RUL-005 |
| Original section | 3.3 |
| Setting key | `tatkal_supplement_ac2` |
| Previous value | INR 400 |
| Revised value | INR 450 |
| Effective date | 2026-11-20 |
| Applicability | Tatkal bookings whose payment and inventory allocation complete on or after 2026-11-20 00:00 Asia/Kolkata |

| Field | Value |
|---|---|
| Original rule | RUL-005 |
| Original section | 3.3 |
| Setting key | `tatkal_supplement_ac3` |
| Previous value | INR 300 |
| Revised value | INR 330 |
| Effective date | 2026-11-20 |
| Applicability | Tatkal bookings whose payment and inventory allocation complete on or after 2026-11-20 00:00 Asia/Kolkata |

## 4. Effective Date and Applicability

The original values apply when both payment and inventory allocation completed before the effective instant. If either step remains incomplete at the effective instant, the system must re-quote the revised supplement before confirmation. Existing completed bookings are not repriced.

## 5. Examples

An AC3 Tatkal booking completed on 2026-11-19 retains the INR 300 supplement. A new AC3 Tatkal booking completed on 2026-11-20 uses INR 330. A pre-effective payment attempt without completed inventory allocation is not a completed booking under RUL-001 Section 3.4 and must be re-quoted.

## 6. Unchanged Provisions

FP remains INR 500, EC INR 350, SL INR 180 and CC INR 150. The 10:00 opening time, two-hour cutoff, four-traveller limit, concession exclusion and cancellation rules in RUL-005 remain unchanged.
