# RAC Aur Waitlist Promotion Edge Case Clarification

## 1. Purpose

Yeh circular batata hai ki ek hi waqt ke aas-paas cancellation hone par RAC aur WL promotion ka order kaise decide hoga. Koi charge, quota ya eligibility condition change nahi ho rahi.

## 2. Reference to Existing Rule

RUL-004 Section 3.3 promotion ko original successful booking timestamp aur system sequence se order karta hai. RUL-004 Section 3.4 ke mutabik mixed-status booking mein har traveller ka status alag record hota hai.

## 3. Clarification

Inventory tabhi released maana jayega jab cancellation booking system mein successfully commit ho jaye. Chat message ka time, preview ka time ya passenger ke pehli baar request bolne ka time inventory release nahi karta. Ek transaction mein multiple seats release hon to waiting travellers ko RUL-004 Section 3.3 ke existing order mein process kiya jayega. System sequence tie-breaker rahega.

Mixed-status booking mein sirf wahi traveller promote hoga jo us class aur quota ke liye next eligible hai. Doosre traveller ka CNF, RAC ya WL status apne aap copy nahi hoga.

## 4. Effective Date and Applicability

Yeh clarification 2026-11-12 00:00 Asia/Kolkata se status-processing aur explanations par apply hoti hai. Kyunki yeh existing logic ko clarify karti hai, yeh purane committed status records ko dobara order nahi karti.

## 5. Example

Agar do cancellations ek saath request hui lekin pehli transaction 10:00:02 par aur doosri 10:00:03 par commit hui, seats isi committed order mein release hongi. Har release par eligible queue RUL-004 Section 3.3 ke original booking timestamp aur system sequence se chalegi.

## 6. English Summary and Unchanged Provisions

Inventory is released only when a cancellation transaction commits, not when chat intent or preview occurs. Promotions retain the ordering in RUL-004 Section 3.3 and remain per traveller. The INR 40 RAC charge, INR 20 WL charge, two-hour automatic WL cancellation, quota boundaries and travel rights are unchanged.
