# Prompts and model used to create the data

**No language model was used to create the data.** All 15 stations, 25 trains, 14 days of seats, 25 passengers, 50 bookings, 12 rules,
6 circulars and 20 FAQs come from `core/seed.py` and `core/content.py` (fixed random seed 42), so the data is identical on every run
and easy to check. Because no model wrote the data, there are no prompts to list. If a team member later uses a model to write
extra documents, add the exact prompt and model name here.
