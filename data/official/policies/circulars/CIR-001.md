# Revised Fixed Cancellation Charges for AC2 and AC3

## 1. Purpose

This circular revises the fixed voluntary-cancellation charges for AC2 and AC3. It is a fictional Ujjwal Rail amendment.

## 2. Reference to Existing Rule

RUL-003 Section 3.3 sets class fixed charges used by the calculation in RUL-003 Sections 3.4 and 3.6. RUL-002 Section 3.4 repeats the same class attributes. Before this circular, AC2 was INR 240 and AC3 was INR 200 per cancelled CNF traveller.

| Effective date | 2026-11-15 |
| Applicability | CNF voluntary-cancellation requests accepted on or after 2026-11-15 00:00 Asia/Kolkata |

From the effective date, RUL-003 Sections 3.4 and 3.6 use these revised minimum fixed charges. The percentage bands and rounding rules do not change.

## 4. Effective Date and Applicability

For a cancellation accepted before 2026-11-15 00:00 Asia/Kolkata, the original INR 240 AC2 and INR 200 AC3 values apply. For a cancellation accepted on or after that instant, INR 260 and INR 220 apply, regardless of booking creation date or journey date. A request started earlier but accepted later uses the later accepted timestamp.

## 5. Examples

An AC2 cancellation accepted on 2026-11-14 uses INR 240 when the class fixed charge is required. An AC2 cancellation accepted on 2026-11-15 uses INR 260. If the applicable percentage deduction is greater, RUL-003 Section 3.6 still selects the greater amount.

## 6. Unchanged Provisions

FP remains INR 300, EC INR 220, SL INR 120 and CC INR 100. Cancellation bands, RAC and WL charges, Tatkal restrictions, fare-component treatment and rounding remain unchanged.
